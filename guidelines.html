04

Scroll Snap System

The page uses CSS scroll snap with a 300vh wrapper + sticky 100vh section pattern. The snap fires at the wrapper level, so the user must scroll 3× a viewport height before the next section snaps into place. This creates the parallax dwell time for the HW overlay effect.

How it works

Wrapper (300vh)
Section (100vh · sticky top:0)
Stays in place while user scrolls 300vh of wrapper

The html element has scroll-snap-type: y mandatory. Each .snap-wrapper is the snap target.

The inner .snap is position: sticky; top: 0 at exactly 100vh. It stays visible the entire time the wrapper scrolls.

The HW overlay parallaxes during this 300vh dwell, rising from the section bottom to near the top.

CSS

/* On <html> */
html {
  scroll-snap-type: y mandatory;
  overflow-y: scroll;
  scroll-behavior: smooth;
}

/* Snap wrapper — the actual snap target */
.snap-wrapper {
  height: 300vh;
  scroll-snap-align: start;
}

/* The visible section — stays put while wrapper scrolls */
.snap {
  height: 100vh;
  position: sticky;
  top: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  border-bottom: 1px solid var(--rule-light);
  overflow: hidden;
  clip-path: inset(0); /* clips GPU-composited layers in Chrome */
}

/* Border variants */
.snap-heavy     { border-bottom: 3px solid var(--ink); }    /* use on first section */
.snap-top-heavy { border-top: 3px solid var(--ink); border-bottom: none; } /* use on last section */

Scrollable sections (overflow content)

When a section's content is taller than the viewport, the JS controller automatically removes the sticky/300vh shell and lets content scroll naturally. The next section only snaps in after the bottom of the content is cleared.

Automatic — no extra markup needed

The JS controller (see Section 09) detects overflow and adds .snap--scrollable automatically on load and resize. Add .snap-no-scroll to a section to opt out of this detection (e.g. the masthead).

HW Overlay System

Handwritten callout text in Chantal 600 italic that parallax-scrolls from the section bottom toward the top during the 300vh dwell. Every section has one HW element, alternating left/right sides.

Base .hw element

/* Applied to every hw element */
.hw {
  grid-row: 1;
  align-self: end;           /* anchors to section bottom — parallax start point */
  z-index: 1;
  position: relative;
  font-family: var(--font-script);   /* chantal */
  font-weight: 600;
  font-style: italic;
  color: var(--accent);
  opacity: 1;
  pointer-events: none;
  line-height: 1.3;
  font-size: clamp(22px, 2.4vw, 38px);
  will-change: transform;
  padding-bottom: 8px;
}

@media (prefers-reduced-motion: reduce) {
  .hw { opacity: 0.18; } /* respect user preferences */
}

Variants

Standard

Side alternation pattern

Sections alternate hw-left / hw-right in order: even-indexed sections use left, odd-indexed use right. The hw element must come before .content-cols in the DOM for correct grid ordering.

<!-- Even section → hw-left -->
<div class="hw hw-left" style="--hw-rot: 2.5deg;">every. single. time.</div>

<!-- Odd section → hw-right -->
<div class="hw hw-right" style="--hw-rot: -2deg;">this is different.</div>

<!-- Hero variant (title section) -->
<div class="hw hw-left hw-hero hw-start-offscreen" style="--hw-rot: 1.5deg;">the truth about AI.</div>

<!-- Hero variant (CTA section) -->
<div class="hw hw-left hw-hero" style="--hw-rot: 2deg;">let's find out.</div>

--hw-rot custom property

Each hw element has a per-element --hw-rot inline style. The JS reads this and applies it as a rotate() in the transform — so rotation is baked per element but driven by JS for consistency with the parallax. On mobile (≤ 600px), the JS multiplies rotation by 3×.

/* Suggested rotation values — vary between +1.5deg and -2.5deg */
style="--hw-rot: 2.5deg;"   /* slight clockwise */
style="--hw-rot: -2deg;"    /* slight counter-clockwise */
style="--hw-rot: 1.5deg;"   /* gentle clockwise */

.hw-hero CSS

.hw-hero {
  font-size: clamp(44px, 4.8vw, 76px); /* 2× the standard hw size */
}

/* Full-width + centred on tablet */
@media (max-width: 900px) {
  .hw-hero { left: 16px; right: 16px; width: auto; text-align: center; }
}

/* Full-width + centred on mobile */
@media (max-width: 600px) {
  .hw-hero { left: 10px; right: 10px; width: auto; font-size: clamp(32px, 10vw, 56px); }

.hw-start-offscreen

Important — always pair with .snap-no-scroll

The parent .snap section must have the snap-no-scroll class to prevent the JS overflow detector from interfering with the start-offscreen positioning. The element starts with visibility: hidden and is revealed by JS once it is safely positioned below the fold.

.hw-start-offscreen {
  visibility: hidden; /* JS sets visibility:visible once transform is applied */
}

09

JS Controller

A single self-contained IIFE at the bottom of <body> handles both overflow detection and parallax. checkOverflow always runs before update — this is critical to avoid race conditions between section type classification and transform calculation.

What it does

checkOverflow()

Measures each section's .content-cols.scrollHeight. If taller than VH - 80px, adds .snap--scrollable and collapses the wrapper to height: auto. Skips sections with .snap-no-scroll.

update()

Reads each .hw element's wrapper position and applies a translateY transform. Sticky sections use wrapper rect; scrollable sections use section rect. Rotation is read from --hw-rot and 3× on mobile.

tick()

Runs checkOverflow() then update() in sequence. Called on load (via document.fonts.ready + double rAF) and on resize. Only update() runs on scroll.

Parallax formulas

Sticky sections (default)

Progress is driven by how far the 300vh wrapper has scrolled.

// wrapper.top: 0 → -(2 × VH) during dwell
progress = clamp(0, 1, -wrapper.top / (VH × 2))
translateY = -progress × VH × 0.75

Scrollable sections

Progress is driven by section position in the viewport.

// section.top: VH → -(sectionH) as it scrolls
progress = clamp(0, 1, (VH - section.top) / (sectionH + VH))
translateY = -progress × sectionH × 0.9

Off-screen start (.hw-start-offscreen)

Only applies to sticky sections. Starts at +VH (below fold) and travels 1.75 × VH total — ending near the top. Also sets visibility: visible so the CSS visibility: hidden default is lifted once JS is in control.

translateY = VH - (progress × VH × 1.75)
hw.style.visibility = 'visible'

Full controller code

<script>
(function () {
  const hwEls = document.querySelectorAll('.hw');
  let rafId = null;

  // ── Overflow detection ──────────────────────────────────────
  function checkOverflow() {
    const VH = window.innerHeight;
    document.querySelectorAll('.snap').forEach(section => {
      if (section.classList.contains('snap-no-scroll')) return;
      const contentCols = section.querySelector('.content-cols');
      if (!contentCols) return;
      const overflows = contentCols.scrollHeight > VH - 80;
      const isScrollable = section.classList.contains('snap--scrollable');
      const wrapper = section.parentElement;
      if (overflows && !isScrollable) {
        section.classList.add('snap--scrollable');
        if (wrapper?.classList.contains('snap-wrapper')) {
          wrapper.style.height = 'auto';
          wrapper.style.minHeight = '100vh';
        }
      } else if (!overflows && isScrollable) {
        section.classList.remove('snap--scrollable');
        if (wrapper?.classList.contains('snap-wrapper')) {
          wrapper.style.height = '';
          wrapper.style.minHeight = '';
        }
      }
    });
  }

  // ── Parallax update ─────────────────────────────────────────
  function update() {
    const VH = window.innerHeight;
    hwEls.forEach(hw => {
      const section = hw.closest('.snap');
      const wrapper = section ? section.parentElement : null;
      if (!wrapper) return;
      const rotBase = parseFloat(
        getComputedStyle(hw).getPropertyValue('--hw-rot').trim()
      ) || -2;
      const rot = rotBase * (window.innerWidth <= 600 ? 3 : 1);
      let progress, travelY;
      if (section.classList.contains('snap--scrollable')) {
        const rect = section.getBoundingClientRect();
        const sectionH = section.offsetHeight;
        progress = Math.max(0, Math.min(1, (VH - rect.top) / (sectionH + VH)));
        travelY = sectionH * 0.9;
      } else {
        const rect = wrapper.getBoundingClientRect();
        progress = Math.max(0, Math.min(1, -rect.top / (VH * 2)));
        if (hw.classList.contains('hw-start-offscreen')) {
          hw.style.transform = `translateY(${VH - progress * VH * 1.75}px) rotate(${rot}deg)`;
          hw.style.visibility = 'visible';
          return;
        }
        travelY = VH * 0.75;
      }
      hw.style.transform = `translateY(${-progress * travelY}px) rotate(${rot}deg)`;
    });
    rafId = null;
  }

  // ── Tick: overflow check then parallax ──────────────────────
  function tick() {
    checkOverflow();
    update();
    rafId = null;
  }

  window.addEventListener('scroll', () => {
    if (!rafId) rafId = requestAnimationFrame(update);
  }, { passive: true });

  window.addEventListener('resize', () => {
    if (!rafId) rafId = requestAnimationFrame(tick);
  }, { passive: true });

  // Wait for fonts + layout before first tick
  function initWhenReady() {
    requestAnimationFrame(() => requestAnimationFrame(tick));
  }
  if (document.fonts && document.fonts.ready) {
    document.fonts.ready.then(initWhenReady);
  } else if (document.readyState === 'complete') {
    initWhenReady();
  } else {
    window.addEventListener('load', initWhenReady);
  }
}());
</script>
