Manifesto Layout System

Guidelines · v2

Overview

A modular, section-based layout kit for long-form manifestos. Every page composes from four primitives: a two-stage snap shell, a 12-column page grid, a 3×3 HW layer for handwritten callouts, and a modular content grid with uniform strokes.

All styling lives in assets/layout.css. All scroll behavior lives in assets/scroll.js. Manifesto HTML files hold only content.

Section skeleton

Every section follows the same structure. The .snap-wrapper is 200vh tall and hosts two 100vh snap stops. Scroll 1 brings content to rest (animating in as the section enters), scroll 2 brings the hw to rest, scroll 3 advances into the next section.

<div class="snap-wrapper">
  <section class="snap">
    <div class="hw-layer">
      <div class="hw" data-hw-pos="bl" style="--hw-rot:-2deg;">callout text</div>
    </div>
    <div class="page-grid">
      <div class="content-cols">
        <div class="mod-grid" style="--cols:2;">
          <div class="mod-cell mod-cell--span mod-cell--kicker">Kicker</div>
          <div class="mod-cell mod-cell--span mod-cell--head"><h2>Headline</h2></div>
          <div class="mod-cell"><p>Left body.</p></div>
          <div class="mod-cell"><p>Right body.</p></div>
        </div>
      </div>
    </div>
  </section>
  <div class="snap-stop" data-stage="1"></div>
  <div class="snap-stop" data-stage="2"></div>
</div>

Two-stage scroll

Two snap stops per section, three user scrolls:

  • Scroll 1 — section enters from below; .content-cols slides up and lands at rest. HW is still below the viewport.
  • Scroll 2 — section is pinned; each .hw slides up from below into its 3×3 anchor.
  • Scroll 3 — advances into the next section (which is that section's scroll 1).

Use the same 200vh wrapper for every section — no variations needed.

If content overflows the viewport, scroll.js adds .snap--scrollable and the section reverts to natural flow so the reader can scroll the content.

HW positioning — 3×3 grid

Place the callout with data-hw-pos. Spreadsheet coordinates: column letter (A=left, B=center, C=right) + row number (1=top, 2=middle, 3=bottom).

Rotation comes from an inline --hw-rot custom property. Tripled automatically on mobile (≤600px).

<div class="hw" data-hw-pos="C1" style="--hw-rot:-1.8deg;">callout</div>
<div class="hw hw-hero" data-hw-pos="A3" style="--hw-rot:1.5deg;">big callout</div>

A section can host multiple .hw children at different positions. Add hw-hero for 2× font size.

Modular content grid

One primitive for all interior layouts. Set column count via --cols. Strokes are uniform (var(--stroke)) on every side.

<div class="mod-grid" style="--cols:3;">
  <div class="mod-cell mod-cell--span mod-cell--kicker">Our Convictions</div>
  <div class="mod-cell mod-cell--span mod-cell--head"><h2>What we believe</h2></div>
  <div class="mod-cell"><p>Point one.</p></div>
  <div class="mod-cell"><p>Point two.</p></div>
  <div class="mod-cell"><p>Point three.</p></div>
  <div class="mod-cell mod-cell--span mod-cell--accent mod-cell--center mod-cell--lead">
    Pull quote across the bottom.
  </div>
</div>

Cell modifiers:

  • --span — cell spans full width.
  • --kicker — small uppercase label in accent color.
  • --head — display headline.
  • --display — extra-large masthead type.
  • --lead — larger body copy.
  • --label, --meta — small uppercase metadata rows.
  • --quiet — muted text color.
  • --accent — accent text color.
  • --center — centered text.

Tokens

:root {
  --cream, --paper, --ink, --ink-light, --ink-mid, --rule-light, --accent;
  --font-display, --font-body, --font-sans, --font-script;
  --grid-gap, --grid-max, --grid-pad;
  --stroke-w, --stroke, --stroke-soft;
  --hw-inset;     /* distance from section edge to hw-layer padding */
}

All borders use var(--stroke) or var(--stroke-soft). Don't introduce ad-hoc pixel widths; change --stroke-w globally to shift the weight.

Responsive behavior

  • ≤ 900px: .page-grid collapses to a single column. HW layer becomes a 2-row grid (top/bottom), 3 cols. All .mod-grid collapse to 1 column.
  • ≤ 600px: HW font size enlarges, z-index lifts above content, rotations triple.
  • reduce-motion: transforms/opacity skip animation and resolve to final state.

Adding a new manifesto

  1. Copy manifesto-chantal.html as a starting point.
  2. Keep the <link rel="stylesheet" href="assets/layout.css"> and <script src="assets/scroll.js" defer></script> refs.
  3. Replace each section's content; choose data-hw-pos per section.
  4. Compose interior using .mod-grid + .mod-cell. Set --cols to 1, 2, 3, etc.
  5. That's the whole system.
